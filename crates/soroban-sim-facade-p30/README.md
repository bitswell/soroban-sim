# soroban-sim-facade-p30

`soroban-sim-facade` built against the protocol-30 Soroban host
(soroban-env-host 30). Its sources are a generated copy of `soroban-sim-facade`;
`soroban-sim` links both, so one binary runs protocol-29 and protocol-30
networks.

Do not edit this crate's sources: edit `soroban-sim-facade` and run
`scripts/sync-protocol-twins.py`. See the
[project documentation](https://github.com/theahaco/soroban-sim).
